# Нобелевские лауреаты

Страны рождения, возраст первой премии, пол и слова из мотиваций. Данные в `data/`.

## запуск

```bash
python -m pip install -r requirements.txt
python -m jupyterlab
```

Открыть `laureates_analysis.ipynb`, затем Restart & Run All.

## тесты

```bash
python -m unittest discover -v
```
