# ДЗ №2 функции и CSV

Python 3.10+, дополнительные библиотеки не нужны. Файл `Corp_Summary.csv` лежит рядом с `hw_functions.py`.

Из папки запустите:

```bash
python hw_functions.py
```

Меню предлагает три действия: вывести департаменты и команды; показать численность сотрудников, диапазон и среднюю зарплату; сохранить сводный CSV в `department_summary.csv`.
