# Avito Academy - Python Basics

ДЗ по основам Python Академии Авито. В папке `python-basics` пять задач

## Задачи

`task_1.py` - Операции с множествами товаров в Москве и Казани
`task_2.py` - Подсчёт поисковых запросов и их частоты |
`task_3.py` - Статистика заказов: возвраты, доставки и средний чек 
`task_4.py` - Выручка и возвраты по дням
`task_5.py` - Статистика отзывов и средних оценок товаров 

## как запустить

нужен **Python 3**

из корня репозитория запустить любую задачу

```bash
python python-basics/task_1.py
```

или

```powershell
py python-basics/task_1.py
```

Для остальных задач заменить `task_1.py` на `task_2.py`, `task_3.py`, `task_4.py` или `task_5.py`.

примеры уже внутри каждого файла. Результат печатается в терминал.
