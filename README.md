# ДЗ по классам

В `hw_classes_base.py` находятся векторизаторы и выделение ключевых слов.

# запуск 
нужен Python 3.9 или новее, зависимости устанавливать не нужно

Запуск из папки проекта:

```bash
python hw_classes_base.py
```

Программа выводит три примера из задания, то есть TF-IDF, настройки и повторное
обучение, ключевые слова. При импорте файла примеры не запускаются
